# Triage labels

Use the GitHub label mapped to each canonical role.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | More information is needed from the reporter. |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified and ready for an agent. |
| `ready-for-human` | `ready-for-human` | Implementation requires a human. |
| `wontfix` | `wontfix` | The issue has been declined. |

Update the GitHub label column if the tracker vocabulary changes.
